An interpreter for make.fun's tiny stack ISA, in one dependency-free `main.ts`:
32-bit wrapping arithmetic, a 256-value data stack, 64 return addresses, 256
words of memory, and every trap with its own exit code. It answers a whole set
of instances in one run, writing each program's output bytes and exit code.
